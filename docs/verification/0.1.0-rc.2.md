# 0.1.0-rc.2 verification

Date: 2026-09-08. Scope: retain Branch Garden and Provider Usage, remove the other five plugins.

The two retained plugins' runtime source and Paseo 0.7.2 API dependencies are unchanged from the previous candidate; only their collection version metadata changes. Earlier live Windows Git-install and RPC evidence remains in the [historical record](https://github.com/SWBaek/Paseo-Plugin/blob/5919ab16fad941d46f2a294e981154f76297cc49/docs/verification/0.1.0-rc.1.md).

## Current checks

`npm run check` passed locally on Windows: documentation synchronization, Git-source imports (16 runtime source files), release metadata, both workspace typechecks and all 50 tests (Branch Garden 27, Provider Usage 23). The lockfile contains only the two current workspaces and matching versions; release checks now reject stale workspace entries. Cross-platform CI results are available on the linked change request.

## Local Paseo cleanup

Before removal, the local Windows daemon listed seven directory-source installations. Their actual runtime IDs and source paths were checked against their manifests. `paseo plugin remove` removed GitHub Project Board, Tailscale Dashboard, Composer Compact, Composer Skills and File Browser. A subsequent listing contained only `branch-garden` and `provider-usage`, both enabled and running without errors. The daemon was not restarted.

The obsolete seven-plugin GitHub draft was deleted. Provider credentials, GitHub authentication, user files and independent Tailscale services were not removed.

UI impact: A for retained plugin views and behavior, which are unchanged. This change removes registrations through Paseo's uninstall lifecycle; no new layout/theme/state code was introduced, so a four-environment screenshot matrix was omitted.

Limits: no new live macOS/Linux or native mobile verification. Provider Usage relies on experimental authenticated usage endpoints. The prior Astra review belongs to the withdrawn candidate and is not claimed as a review of this removal.
